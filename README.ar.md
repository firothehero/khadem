# خادم — وكيل الذكاء الاصطناعي العربي

**خادم** وكيل ذكاء اصطناعي عربي متقدّم مبني على [Hermes Agent](https://github.com/NousResearch/hermes-agent):
يتعلّم من تجاربه، ويتذكّر، ويعمل على جهازك أو خادمك، ويتحدث معك بالعربية الفصحى أو بلهجتك.

## ما الذي يضيفه خادم؟

- **العربية أولاً:** الواجهة والرسائل وطلبات الموافقة والطرفية بالعربية افتراضياً، مع إبقاء اختيارك إن غيّرت اللغة.
- **هوية خادم:** شخصية عربية مهذبة ودقيقة، تكتب بفصحى أنيقة وعلامات ترقيم عربية، وتعرف تاريخ اليوم بالميلادي والهجري.
- **أدوات عربية:**
  - `arabic_text`: تطبيع النص العربي، إزالة التشكيل، تحويل الأرقام (٠-٩ ↔ 0-9)، كتابة الأعداد بالحروف، و**التفقيط** للشيكات والفواتير بعشرين عملة (ريال، درهم، دينار، جنيه…)، وإحصاءات النص.
  - `hijri_date`: التحويل بين الهجري والميلادي وفق **تقويم أم القرى** الرسمي.
- **مهارات عربية:** الكتابة والتدقيق، الترجمة والتوطين، المستندات العربية من اليمين إلى اليسار (Word وPDF وExcel وPowerPoint)، اللهجات والعربيزي، التقويم الهجري، ومعالجة النصوص العربية برمجياً.
- **مظهر خادم للطرفية:** ألوان زمردية وذهبية وعبارات عربية.

## التثبيت

ثبّت كما في الدليل الإنجليزي ([README.md](README.md)) مع الإشارة إلى مستودع خادم:

```bash
HERMES_REPO_URL=https://github.com/firothehero/khadem.git \
  bash -c "$(curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh)"
```

أو استخدم **تطبيق خادم لسطح المكتب** الذي يثبّت كل شيء ويضبطه بالعربية تلقائياً.

إيقاف طبقة خادم مؤقتاً: `hermes plugins disable khadem` أو المتغيّر `KHADEM_DISABLE=1`.

## للمطوّرين

كل ما يخص خادم موجود في `plugins/khadem/` دون أي تعديل على ملفات Hermes الأصلية، لذا يمكن دمج أحدث إصدار من Hermes في أي وقت:

```bash
scripts/khadem/sync-upstream.sh
```

التفاصيل الكاملة (البنية، الفحوص، وسجل التعديلات) في [KHADEM.md](KHADEM.md).
